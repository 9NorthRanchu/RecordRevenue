# archive — ไฟล์ที่ใช้ครั้งเดียวแล้ว (ย้ายมาเก็บ 2026-10-11)

ย้ายออกจากโฟลเดอร์หลักเพื่อให้เห็นเฉพาะไฟล์ที่ยังใช้อยู่ — **ไม่มีโค้ดของระบบอ้างถึงไฟล์ในนี้** (ตรวจแล้วก่อนย้าย)

- `scripts/` — สคริปต์แก้โค้ดครั้งเดียว (fix_*, patch_*, update_*), ทดสอบชั่วคราว (test_*), GoogleSheetsSync.js (เลิกใช้แล้ว)
- `sql/` — SQL ที่รันกับฐานข้อมูลไปแล้วในอดีต (ปัจจุบันใช้ `setup-db.sh` ซึ่งรันซ้ำได้ปลอดภัย)
  - `backup-before-trip-finance.sql` = ข้อมูลการเงินจริง — อยู่ใน .gitignore ห้ามขึ้น GitHub
- `misc/` — ไฟล์ออกแบบหน้าจอรุ่นทดลอง, captions-backup.json

ถ้าต้องใช้ไฟล์ไหนอีก ย้ายกลับไปที่เดิมได้เลย
